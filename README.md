# Donnie-host2

This repository now includes a simple download landing page for the Generational Curses Breaker APK.

To use it:

1. Upload the APK file to a GitHub Release named something like `Generational-Curses-Breaker.apk`.
2. Make sure the download URL in `index.html` matches the final release asset URL.
3. Open the GitHub Pages site or use the static page directly.

The site is ready in `index.html` and `styles.css`.
